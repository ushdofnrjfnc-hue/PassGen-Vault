# Техническое задание: PassGen & Vault

## 1. Введение
PassGen & Vault – desktop-приложение для генерации надежных паролей и ведения их локальной истории. Предназначено для пользователей, которым требуется быстро создавать сложные пароли и сохранять их в структурированном виде.

## 2. Требования к программе
### 2.1 Функциональные требования
- Генерация пароля заданной длины (от 4 до 64 символов).
- Выбор наборов символов: заглавные буквы, строчные буквы, цифры, спецсимволы.
- Копирование результата в буфер обмена ОС.
- Сохранение пароля в файл истории (формат CSV с разделителем `;`).
- Очистка файла истории.

### 2.2 Требования к надёжности
При некорректном вводе данных (например, буквенное значение в поле длины) приложение должно отображать диалоговое окно с ошибкой и не завершаться аварийно.

### 2.3 Условия эксплуатации и совместимость
Приложение рассчитано на работу на персональном компьютере под управлением Windows, Linux или macOS с установленным Python 3.9+.

## 3. Требования к интерфейсу
Графический интерфейс (Tkinter) должен содержать:
- Поле ввода для указания длины пароля.
- 4 чекбокса для выбора наборов символов.
- Поле вывода (Entry) для отображения сгенерированного пароля.
- Кнопки управления: «Сгенерировать», «Копировать», «Сохранить в историю», «Очистить историю».
- Статусную строку в нижней части окна для отображения текущих действий.

## 4. Критерии приемки
Продукт считается принятым, если не менее 90% тест-кейсов по функциям генерации, копирования и сохранения истории завершаются успешно (статус Passed).
