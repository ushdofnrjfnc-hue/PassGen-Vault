# PassGen & Vault

Настольное приложение для генерации надежных паролей заданной длины и набора символов, а также для ведения локальной истории сгенерированных паролей в формате CSV.

## Возможности
- Генерация пароля длиной от 4 до 64 символов.
- Гибкая настройка набора символов (заглавные/строчные буквы, цифры, спецсимволы).
- Копирование результата в буфер обмена.
- Сохранение истории генерации в CSV-файл с временной меткой.
- Функция очистки истории.

2. Скачайте или клонируйте данный репозиторий.
3. Откройте терминал (командную строку) в папке с проектом.
4. Запустите приложение командой:
   ```bash
   python main.py
